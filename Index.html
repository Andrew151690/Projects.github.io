INLINE

Qué son los elementos inline

Los elementos inline se colocan dentro de un texto y no rompen la línea. Sirven para darle estilo o significado a fragmentos específicos.

Ejemplos de etiquetas inline más comunes

  • <span> = Contenedor genérico en línea, útil para estilos o scripts.
  • <strong> = Resalta importancia (negrita).
  • <em> = Resalta énfasis (cursiva).
  • <u> = Subraya el texto.
  • <mark> = Resalta con fondo amarillo.
  • <abbr> = Abreviatura con significado, puede mostrar tooltip.
  • <code> = Representa código en línea.
  • <b> = Texto en negrita, sin implicar importancia.
  • <i> = Texto en cursiva, sin implicar énfasis.
  • <a> = Enlace en línea.

Ejemplo práctico

En Jujutsu Kaisen, Yuji Itadori come un dedo maldito para ganar poder. Su habilidad Cursed Energy es increíble. Puedes ver más en la wiki oficial. Código inline: <strong>Cursed Energy</strong>.

BLOCK

Qué son los elementos block

Los elementos block ocupan todo el ancho disponible, siempre empiezan en una nueva línea y pueden contener otros elementos block o inline.

Ejemplos de etiquetas block más comunes

  • <div> = Contenedor genérico para agrupar contenido.
  • <section> = Sección semántica de contenido relacionado.
  • <article> = Contenido independiente, como un post o noticia.
  • <header> = Encabezado de página o sección.
  • <footer> = Pie de página de sección o sitio.
  • <nav> = Contenedor de enlaces de navegación.
  • <main> = Contenido principal de la página.
  • <h1>…</h6> = Encabezados de diferentes niveles.
  • <p> = Párrafo de texto.
  • <form> = Formulario (puede contener otros elementos).
  • <table> = Tablas completas.
  • <blockquote> = Cita larga.

INLINE-BLOCK

Qué es Inline-Block

El inline-block combina características de inline y block:

  • No rompe la línea como un block (puede estar junto a otros elementos inline-block).
  • Se le pueden aplicar ancho (width) y alto (height) como un block.
  • Perfecto para elementos que quieres que se alineen horizontalmente pero manteniendo dimensiones.

Ejemplo práctico: Personajes de Jujutsu Kaisen

Yuji Itadori

Protagonista principal, tragó un dedo maldito para ganar poder.

Satoru Gojo

El hechicero más fuerte, maestro de Yuji y experto en Domain Expansion.

Nobara Kugisaki

Hechicera joven y poderosa, usa clavos y martillo como armas malditas.

Observa cómo estos bloques están alineados horizontalmente gracias a display: inline-block; pero todavía puedes darles ancho, alto, padding y border como elementos block.

Observa cómo display cambia el comportamiento de cada elemento:

  • block ocupa toda la línea y genera saltos.
  • inline no ocupa toda la línea y se alinea con otros elementos.
  • inline-block se comporta como block pero se puede alinear en línea.
  • flex permite crear contenedores flexibles y alinear elementos fácilmente.
  • grid permite crear layouts en filas y columnas con gran control.

class se usa para agrupar varios elementos que comparten un estilo o función. id identifica un único elemento en la página.

BOX MODEL

Qué es el Box Model

Cada elemento HTML se representa como un rectángulo y está compuesto por varias capas:

  • Content = Contenido del elemento (texto, imagen, etc.)
  • Padding = Espacio interior entre el contenido y el borde
  • Border = Borde del elemento
  • Margin = Espacio exterior entre este elemento y otros

Ejemplo visual: Personaje de Jujutsu Kaisen

Satoru Gojo

El hechicero más fuerte, maestro de Yuji.

Content = Imagen + texto
Padding = 20px alrededor del contenido

Margin = 20px fuera de la tarjeta

Observa cómo el padding separa el contenido del borde, el border lo delimita, y el margin lo separa de otros elementos.
